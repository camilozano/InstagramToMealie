# Memory Bank

This directory serves as the memory bank for the Instagram to Mealie project. It contains documentation and context that is essential for understanding and working with the project.

## Purpose

The Memory Bank provides a comprehensive overview of the project, including its goals, architecture, technical details, and current status. It serves as a single source of truth for the project's documentation.

## Structure

The Memory Bank is organized into the following core files:

1. **projectbrief.md**: Foundation document that defines core requirements and goals
2. **productContext.md**: Why this project exists, problems it solves, and how it should work
3. **systemPatterns.md**: System architecture, key technical decisions, and design patterns
4. **techContext.md**: Technologies used, development setup, and technical constraints
5. **activeContext.md**: Current work focus, recent changes, and next steps
6. **progress.md**: What works, what's left to build, and known issues

## Usage

- Reference these files to understand the project's purpose, architecture, and current state
- Update the files as the project evolves to maintain accurate documentation
- Use the Memory Bank as a starting point for onboarding new contributors

## Maintenance

- Keep the Memory Bank up to date as the project evolves
- Ensure that all major decisions and changes are documented
- Review and update the Memory Bank regularly to reflect the current state of the project
